# OSCE 演練後回饋

讀取 [assets/feedback-instructions.txt](assets/feedback-instructions.txt)，依該規則評分。需要本站病例及對話；缺少其中之一，先取得資料或只回覆可判斷的部分，不新增評分項目或補造表現。

從結束口令之後開始；若仍在演練中，先確認要停止演練並切換回饋。對獨立提供的舊逐字稿，可直接回饋。

保留來源站次、病例版本、練習次數、提示狀態與逐字稿完整性。對話證據引用短句或訊息編號；AI 推測不能當學生說過的話。聲音語調或非語言評量只有相應原始資料及明確規準可用時才討論，純文字紀錄不得給這類分數。

輸出先給三個口頭重點，再給逐項表格。分數、可觀察項目分母及不可評項目分開列。達標分數由教師另訂；沒有設定就不自行判定通過。評分與建議屬形成性練習，若需作正式考試或教育研究資料，需另行教師校準與驗證。
