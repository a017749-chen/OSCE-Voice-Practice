# OSCE 語音標準化病人練習

讓醫學系實習醫學生從一個練習想法出發，建立 OSCE 教案，並用 ChatGPT 語音練習病史詢問或醫病溝通。AI 在演練中扮演病人；你說「結束演練」後，它才依對話提供形成性回饋。

**不需要安裝程式就能試用兩個示範。** 病例均為虛構，預設每站 8 分鐘、15 項評分項目。

## 先練一站

| 站次 | 練習 | 下載演練包 | 考生指引 |
|---|---|---|---|
| HX-001 | 反覆上腹痛病史詢問 | [下載 TXT](examples/HX-001/voice-packet.txt?raw=1) | [閱讀指引](examples/HX-001/candidate.md) |
| COM-001 | 健檢結果與生活調整溝通 | [下載 TXT](examples/COM-001/voice-packet.txt?raw=1) | [閱讀指引](examples/COM-001/candidate.md) |

1. 下載一份 TXT。若 GitHub 顯示檔案內容而未下載，可按檔案頁右上角的 **Download raw file**，或儲存成 UTF-8 純文字檔。
2. 開啟 [ChatGPT](https://chatgpt.com/) 新聊天，上傳該 TXT，並輸入：

   > 請依附件載入本站，只顯示考生指引，確認可開始後等待我。

3. 確認站次與版本後，在**同一個聊天**開啟語音。使用手機或其他計時器倒數 8 分鐘，說「開始演練」。
4. 與病人對話；想結束時說「結束演練」，再查看逐項回饋與對話證據。

語音及檔案上傳功能依帳號、裝置和設定而異。若附件無法讀取，請改貼 TXT 內容；若切到語音後忘記病例，先重新載入。外部計時器由使用者操作。

| 口令 | 用途 |
|---|---|
| 開始演練 | 進入病人角色 |
| 暫停演練／繼續演練 | 暫停或接續互動，也要自行暫停／恢復計時器 |
| 目前狀態 | 查詢目前階段與站次 |
| 結束演練 | 結束病人角色，開始形成性回饋 |
| 重新練習 | 以同一病例重新開始 |

## 用網頁版 ChatGPT 把自己的 idea 變成考題

以下流程不需要安裝程式或 skill。先在一個聊天出題，再另開聊天進行標準化病人練習。

### 第一步：複製出題指令

1. 開啟[學生出題啟動指令](prompts/idea-to-case.txt)。
2. 複製**整份文字**，包括後半段的標準化病人規則。可以使用 GitHub 檔案頁右上角的複製按鈕，或先選 Raw 再全選複製。
3. 開啟 [ChatGPT 網頁版](https://chatgpt.com/)的新聊天，貼上剛才複製的指令，再加上自己的 idea。例如：

   > 我是醫學系實習醫學生，想練習急診胸痛病人的病史詢問。請用合理預設製作一個 8 分鐘的 OSCE 站，並產生完整教案、考生指引及標準化病人語音演練包。練習前只顯示考生指引。

### 第二步：確認藍圖並取得演練包

GPT 可能會詢問站型、目標或情境；可以回答問題，也可以說「用建議的預設值」。確認後，請它產生：

- **考生指引**：練習前閱讀的背景與任務。
- **完整教案**：包含評分錨點、考官及 SP 指引，供出題學習或教師審閱。
- **語音演練包 TXT**：包含固定病史、資訊揭露規則、評分錨點及演練指令，供下一個聊天使用。

如果 GPT 沒有提供演練包，可以接著輸入：

> 請把本題的標準化病人語音演練包整理成一份可下載的 TXT，包含病人設定、資訊揭露規則、評分錨點和演練與回饋指令。若無法產生檔案，請把完整內容放在文字框中供我複製。

如果只能取得文字，複製後存成 UTF-8 的 `.txt` 檔。若 GPT 支援產生 Word，也可另外要求可下載的完整教案；無法產檔時可先使用 Markdown 文字。

### 第三步：開啟語音練習

1. **另開一個 ChatGPT 聊天**，上傳剛才的語音演練包，輸入：

   > 請依附件載入本站，只顯示考生指引，確認可開始後等待我。

2. 確認 GPT 已讀取正確站次後，在**同一個聊天**開啟語音，用手機或其他計時器倒數 8 分鐘，說「開始演練」。
3. 與病人對話，時間到或想結束時說「結束演練」，再查看逐項回饋與對話證據。

若附件讀不到，可將完整演練包文字貼入新聊天。演練包和完整教案都包含答案；若在複製或閱讀時看過病人設定，這次就屬於「已知題」練習。

### 已有教案時

上傳完整教案，再貼上[通用標準化病人指令](prompts/standardized-patient.txt)。若教案沒有足夠的病人設定或評分錨點，應先補齊，不應由 AI 虛構評分依據。

## 使用界線

- 教師應在課程使用前審閱病例、評分錨點與 8 分鐘可行性。語音真人試跑與評分者校準目前尚未完成；已有測試及限制見[驗證紀錄](docs/validation.md)。
- AI 回饋只作**形成性練習**。逐字稿缺段或語音辨識不清時，相關項目應列為「無法判斷」，不應推測學生的眼神、身體檢查或未記錄表現。
- 演練包與完整教案含答案，拿到檔案的人可以閱讀；這不是保密機制。看過答案後的練習屬已知題。
- 請使用虛構或經授權且不含可識別病人資訊的材料。本站不能取代臨床照護、教師判斷或正式 OSCE 考試。
